## Raw Data

### Subnational HDI Data v8.3.csv

**Source:** Global Data Lab, Institute for Management Research, Radboud University

**URL:** https://globaldatalab.org/shdi/

**License:** Creative Commons BY 4.0

**Description:**
Comprehensive dataset containing Human Development Index values at the subnational level for regions worldwide.

**Coverage:**
- **Regions:** 1,600+ subnational regions
- **Countries:** 160+ countries
- **Years:** 1990-2022 (33 years)
- **Total Observations:** 61,180 region-year combinations

**Key Columns:**

*Identifiers:*
- `isocode3`: ISO 3-letter country code
- `country`: Country name
- `gdlcode`: Unique subnational region identifier
- `level`: Level of aggregation ("National" or "Subnat")
- `region`: Subnational region name
- `year`: Year of observation (1990-2022)

*HDI Components:*
- `shdi`: Subnational Human Development Index (0-1 scale)
- `healthindex`: Health component based on life expectancy (0-1)
- `edindex`: Education component (0-1)
- `incindex`: Income component based on GNI per capita (0-1)

*Raw Indicators:*
- `lifexp`: Life expectancy at birth (years)
- `esch`: Expected years of schooling (years)
- `msch`: Mean years of schooling for adults 25+ (years)
- `lgnic`: Log of Gross National Income per capita (2017 PPP USD)

*Gender-Disaggregated Values:*
- Variables with `f` suffix: Female-specific values
- Variables with `m` suffix: Male-specific values
- `sgdi`: Subnational Gender Development Index

**Data Quality Notes:**
- Gender-disaggregated data only available from 2000 onwards
- Some regions have incomplete time series
- Missing values are present, especially in early years
- Some small regions may have limited data availability

## HDI Methodology

### Component Calculation

**Health Index:**
Based on life expectancy at birth, normalized to a 0-1 scale using:
- Minimum value: 20 years
- Maximum value: 85 years

**Education Index:**
Arithmetic mean of two sub-indices:
1. Mean years of schooling (adults 25+)
   - Minimum: 0 years
   - Maximum: 15 years
2. Expected years of schooling (children)
   - Minimum: 0 years
   - Maximum: 18 years

**Income Index:**
Based on logarithm of GNI per capita (2017 PPP USD):
- Minimum: $100
- Maximum: $75,000
- Logarithmic transformation reflects diminishing returns of income

### HDI Calculation

The HDI is the geometric mean of the three component indices:

```
HDI = (Health_Index × Education_Index × Income_Index)^(1/3)
```

The geometric mean ensures that poor performance in one dimension cannot be fully compensated by high performance in another, emphasizing balanced development.

### Bottleneck Identification

The bottleneck is defined as the component with the lowest index value:

```
Bottleneck = arg min(Health_Index, Education_Index, Income_Index)
```

This identifies which dimension is most limiting overall human development and should be prioritized for policy intervention.

## Data Processing Pipeline

The processing pipeline:
1. Loads raw data
2. Validates required columns
3. Filters to subnational level only
4. Cleans and standardizes data types
5. Adds continent mapping
6. Saves processed data

To regenerate processed data:

```python
from src.data_processing import process_all_data

# Process raw data and save to processed directory
df = process_all_data(
    raw_filepath="data/raw/Subnational HDI Data v8.3.csv",
    output_dir="data/processed/"
)
```

Or from command line:

```bash
python -c "from src.data_processing import process_all_data; process_all_data()"
```

**Note:** The preprocessing only handles data loading and cleaning. All analysis (bottleneck detection, clustering, statistical analysis) is performed on-demand in the visualization layer for maximum flexibility.

## Updates

The Global Data Lab periodically releases updated versions of the SHDI dataset. To use newer data:

1. Download the latest CSV file from https://globaldatalab.org/shdi/
2. Replace the file in `data/raw/`
3. Update the filename in `config/app_config.yaml` if changed
4. Run the data processing pipeline to regenerate processed files

This dataset contains aggregated statistics at the regional level and does not include individual-level data. All data is publicly available and released under Creative Commons BY 4.0 license.
